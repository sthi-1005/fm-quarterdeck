# Quarterdeck product experience

One captain. One Firstmate. A clear view of the whole fleet.

Start with the [visual product guide](visual/index.html): current screenshots with clickable intent and implementation notes. The text below remains the editable specification.

Quarterdeck should make it easy to return, understand what changed and respond without managing separate worker conversations. Firstmate interprets your requests and owns orchestration.

## Everyday experience

- **Scan:** see calls, landed outcomes, work underway and what is next.
- **Understand:** read the actual question and available context; inspect details only when useful.
- **Respond:** talk naturally to Firstmate, with the relevant card or message attached.
- **Look away:** trust recorded outcomes and honest gaps rather than babysitting workers.

Automatic card updates protect typing. Deliberate departures/reloads discard raw drafts. Composer and annotation history stays until Clear messages; delivery evidence has its own lifetime.
